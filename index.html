1cdx
Fitur Roadmap DeX GitHub

Preview Android · Kotlin · Samsung DeX

Code editor ringan dengan SFTP bawaan untuk Android.

1cdx sedang dibangun untuk alur kerja ini: buka folder di server lewat SFTP, edit kodenya di tablet atau ponsel yang tersambung ke DeX, lalu tekan Ctrl+S dan file langsung ter-upload ke server.

Unduh Preview Catatan rilis

Rilis terbaru dari GitHub Releases · Android 8.0+

Masih tahap awal pengembangan. Build preview belum memuat fitur di bawah. Lihat roadmap untuk statusnya.

Fitur yang direncanakan

Setiap fitur diberi label milestone tempat fitur itu dikerjakan.

Milestone 1

Editor native yang cepat

Dibangun dengan Kotlin dan sora-editor. Ada syntax highlighting TextMate, tema ala VS Code, code folding, bracket matching, dan multi-cursor. Targetnya tetap responsif di file puluhan ribu baris.

Milestone 2

SFTP client terintegrasi

Kelola profil server dengan password atau SSH key (ed25519, ecdsa, rsa). Folder dimuat saat dibuka saja, jadi hemat bandwidth.

Milestone 2

Auto-upload saat simpan

File disimpan dulu ke cache lokal, lalu di-upload di background. Kalau jaringan putus, perubahan tetap aman dan 1cdx akan tersambung ulang otomatis.

Milestone 2

Kredensial terenkripsi

Password dan private key disimpan lewat Android Keystore, tidak pernah sebagai plain text.

Milestone 1

Multi-tab & status bar

Tab dengan penanda perubahan yang belum disimpan. Status bar menampilkan koneksi, bahasa, posisi kursor, dan status sinkronisasi.

Sepanjang proyek

Ringan

Bukan WebView atau Electron. Target pemakaian RAM di bawah 120 MB meski banyak tab terbuka.

Dirancang untuk Samsung DeX

Layout split-pane yang bisa diubah ukurannya, klik kanan mouse untuk menu konteks, dan shortcut keyboard yang biasa dipakai di desktop. Shortcut dasar dikerjakan di Milestone 1, panel terminal di Milestone 3.

Ctrl+SSimpan & upload ke server
Ctrl+BTampilkan/sembunyikan explorer
Ctrl+PCari file cepat
Ctrl+FFind & replace
Ctrl+WTutup tab
Ctrl+`Panel terminal SSH

Roadmap

  1. Sedang dikerjakan

    Milestone 1: Core Editor & DeX Layout

    Editor dengan syntax highlighting, layout split-pane yang bisa di-resize, multi-tab, dan shortcut keyboard dasar. Sementara bekerja pada file lokal.

  2. Direncanakan

    Milestone 2: SFTP Engine & Sync

    Connection manager terenkripsi, file explorer remote, auto-upload saat Ctrl+S, dan auto-reconnect.

  3. Direncanakan

    Milestone 3: Polishing & Terminal SSH

    Menu klik kanan lengkap, status sinkronisasi, penanganan error jaringan, dan panel terminal SSH.

Cara pasang

  1. Unduh 1cdx.apk dari rilis preview terbaru.
  2. Buka file APK lalu izinkan instalasi dari sumber ini jika diminta.
  3. Rilis berikutnya bisa langsung dipasang di atas versi lama karena memakai sertifikat yang sama.

Build preview dibuat otomatis dari setiap perubahan dan isinya bertambah mengikuti roadmap. Verifikasi file dengan SHA256SUMS.txt di halaman rilis.
