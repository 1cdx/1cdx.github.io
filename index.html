Fitur

Editor native yang cepat

Dibangun dengan Kotlin dan sora-editor. Ada syntax highlighting TextMate, tema ala VS Code, code folding, bracket matching, dan multi-cursor. Targetnya tetap responsif di file puluhan ribu baris.

SFTP client terintegrasi

Kelola profil server dengan password atau SSH key (ed25519, ecdsa, rsa). Folder dimuat saat dibuka saja, jadi hemat bandwidth.

Auto-upload saat simpan

File disimpan dulu ke cache lokal, lalu di-upload di background. Kalau jaringan putus, perubahan tetap aman dan 1cdx akan tersambung ulang otomatis.

Kredensial terenkripsi

Password dan private key disimpan lewat Android Keystore, tidak pernah sebagai plain text.

Multi-tab & status bar

Tab dengan penanda perubahan yang belum disimpan. Status bar menampilkan koneksi, bahasa, posisi kursor, dan status sinkronisasi.

Ringan

Bukan WebView atau Electron. Target pemakaian RAM di bawah 120 MB meski banyak tab terbuka.

Dirancang untuk Samsung DeX

Layout split-pane yang bisa diubah ukurannya, klik kanan mouse untuk menu konteks, dan shortcut keyboard yang biasa dipakai di desktop.

Cara pasang

  1. Unduh 1cdx.apk dari rilis terbaru.
  2. Buka file APK lalu izinkan instalasi dari sumber ini jika diminta.
  3. Rilis berikutnya bisa langsung dipasang di atas versi lama karena memakai sertifikat yang sama.

1cdx masih dalam tahap pengembangan awal. Verifikasi file dengan SHA256SUMS.txt di halaman rilis.
